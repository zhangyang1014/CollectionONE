```javascript
  let content = templateContent

  // 替换贷款金额（需要格式化）
```

### 2. 后端API更新

**文件**: `backend-java/src/main/java/com/cco/controller/MockMessageTemplateController.java`

#### 2.1 VariableVO类增加字段

```java
@Data
public static class VariableVO {
    private String name;        // 变量名
    private String key;         // 变量标识 {变量名}
    private String fieldKey;    // 字段标识，对应甲方字段展示配置中的field_key
    private String type;        // 数据类型
    private String example;     // 示例值
    private String description; // 说明
    
    public VariableVO(String name, String key, String fieldKey, String type, String example, String description) {
        this.name = name;
        this.key = key;
        this.fieldKey = fieldKey;
        this.type = type;
        this.example = example;
        this.description = description;
    }
}
```

#### 2.2 更新getVariables()方法


## 🔗 技术关联

### 数据流转

```
甲方字段展示配置 (tenant_field_display_configs)
    ↓
    field_key 映射
    ↓
消息模板变量系统
    ↓
    变量替换引擎
    ↓
实际发送的消息内容
```

| 数据层 | `tenant_field_display_configs` 表 | 存储字段配置 |
