## 📝 如何使用Mock数据

### 导入完整数据（推荐）

```bash
# 导入所有表结构和Mock数据
mysql -u root -p < backend-java/database-export/cco_system_complete_20251212_095546.sql
```

### 验证导入结果

```bash
# 检查案件数据
mysql -u root -p cco_system -e "SELECT COUNT(*) as total FROM cases;"

# 查看案件状态分布
mysql -u root -p cco_system -e "
SELECT 
    case_status, 
    COUNT(*) as count 
FROM cases 
GROUP BY case_status;
"

# 查看逾期天数分布
mysql -u root -p cco_system -e "
SELECT 
    CASE 
        WHEN overdue_days = 0 THEN '已结清'
        WHEN overdue_days BETWEEN 1 AND 5 THEN '1-5天'
        WHEN overdue_days BETWEEN 6 AND 30 THEN '6-30天'
        WHEN overdue_days BETWEEN 31 AND 90 THEN '31-90天'
        ELSE '90天以上'
    END as overdue_range,
    COUNT(*) as count
FROM cases
GROUP BY overdue_range
ORDER BY MIN(overdue_days);
"
```

### 查看Mock数据

