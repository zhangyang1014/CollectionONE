# 案件详情字段隐藏规则 PRD

## 1. 背景与目标
- 敏感字段（如证件号、收入等）需要按案件队列差异化展示，避免无关角色看到。
- 提供可配置的队列级隐藏能力，满足合规与最小权限原则。

## 2. 范围说明
- 适用页面：案件详情页（控台、催员端共用配置）。
- 支持维度：仅按案件所属队列隐藏。
- 不在范围：按机构 / 小组隐藏（本版本不支持）。
- 默认行为：未配置时字段正常展示。

## 3. 配置入口与操作
- 入口：`案件详情字段展示配置` 页面 → 字段行“编辑” → 对话框“隐藏规则”页签。
- 交互：
  - 多选下拉选择需要隐藏的队列。
  - 保存后写入字段配置版本，批量保存后生效。
- 文案提示：仅说明“基于案件所属队列生效”。

## 4. 生效规则
- 判断依据：案件的 `queue_id` 是否包含在字段的 `hide_for_queues` 中。
- 若匹配：该字段在详情页不展示（控台 & 催员端）。
- 若不匹配或未配置：字段照常展示。
- 优先级：隐藏规则高于其他展示属性（颜色、分组等）。

## 5. 数据与接口
- 数据结构：在字段配置中新增/使用 `hide_for_queues: string[]`。
- 示例：
```json
{
  "field_key": "id_number",
  "field_name": "身份证号",
  "hide_for_queues": ["1001", "2002"]
}
```
- 存储/读取：沿用现有字段展示配置接口（读取与保存接口保持不变，只增加字段值）。

## 6. 验收与测试
- 配置后在案件详情页验证：位于隐藏队列的案件，看不到被配置隐藏的字段；其他队列可正常看到。
- 边界：
  - 未选择甲方时不加载队列，提示选择甲方。
  - 队列数据加载失败时提示错误，保持空列表。
  - 保存后重新打开配置，已选队列应正确回显。
- 回归：确认未配置隐藏规则的字段不受影响，列表/筛选等功能无回归。
