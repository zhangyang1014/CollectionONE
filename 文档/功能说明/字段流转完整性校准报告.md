# 字段流转完整性校准报告

## 📋 概述

本文档说明了CCO系统中"甲方字段展示配置"在三个关键场景的完整应用情况。

## 🎯 三个关键场景

### 1. 控台案件列表 (admin_case_list)

**路径**: `frontend/src/views/case-management/CaseList.vue`

**场景说明**: 管理后台的案件列表页面,供SuperAdmin和TenantAdmin使用。

#### ✅ 已实现功能

1. **字段展示配置读取**
   - 使用 `useFieldDisplayConfig` Hook
   - 场景类型: `admin_case_list`
   - 根据甲方ID动态加载配置

2. **动态表格列渲染**
   - 使用 `DynamicCaseTable` 组件
   - 自动应用字段配置的:
     - ✅ 显示宽度 (`display_width`)
     - ✅ 字段对齐 (`align`)
     - ✅ 颜色类型 (`color_type`)
     - ✅ 格式化规则 (`format_rule`)
     - ✅ 排序支持 (基于 `is_range_searchable`)

3. **筛选功能应用**
   - ✅ **可搜索字段** (`is_searchable`): 文本字段模糊搜索
   - ✅ **可筛选字段** (`is_filterable`): 枚举字段下拉筛选
   - ✅ **范围检索字段** (`is_range_searchable`): 数字和日期字段范围筛选

4. **数据格式对齐**
   ```typescript
   // 货币格式
   { format_type: 'currency', prefix: '¥', suffix: '' }
   
   // 百分比格式
   { format_type: 'percentage', suffix: '%' }
   
   // 日期格式
   YYYY-MM-DD HH:mm:ss
   ```

#### 代码示例

```vue
<template>
  <DynamicCaseTable
    :data="displayCases"
    :columns="getTableColumns()"
    :loading="configLoading"
    show-actions
    :actions-width="200"
  >
    <!-- 自定义字段渲染插槽 -->
    <template #cell-overdue_days="{ row }">
      <el-tag :type="getOverdueTagType(row.overdue_days)">
        {{ row.overdue_days }} 天
      </el-tag>
    </template>
  </DynamicCaseTable>
</template>

<script setup lang="ts">
import { useFieldDisplayConfig } from '@/composables/useFieldDisplayConfig'

const {
  visibleConfigs,
  searchableFields,
  filterableFields,
  rangeSearchableFields,
  getTableColumns
} = useFieldDisplayConfig({
  tenantId: currentTenantId,
  sceneType: 'admin_case_list',
  autoLoad: true
})
</script>
```

## 🔧 技术架构

### 1. 统一Hook: useFieldDisplayConfig

**文件**: `frontend/src/composables/useFieldDisplayConfig.ts`

**功能**:
- 封装字段展示配置的读取逻辑
- 提供计算属性筛选不同类型字段
- 提供工具方法格式化字段值
- 支持隐藏规则判断

**核心API**:

```typescript
export function useFieldDisplayConfig(options: {
  tenantId: Ref<number | null>
  sceneType: 'admin_case_list' | 'collector_case_list' | 'collector_case_detail'
  autoLoad?: boolean
}) {
  return {
    // 状态
    loading: Ref<boolean>
    configs: Ref<FieldDisplayConfig[]>
    visibleConfigs: ComputedRef<FieldDisplayConfig[]>
    
    // 分类字段
    searchableFields: ComputedRef<FieldDisplayConfig[]>
    filterableFields: ComputedRef<FieldDisplayConfig[]>
    rangeSearchableFields: ComputedRef<FieldDisplayConfig[]>
    
    // 方法
    loadConfigs: () => Promise<void>
    getFieldWidth: (fieldKey: string) => number | undefined
    getFieldColorType: (fieldKey: string) => string
    getFieldAlign: (fieldKey: string) => 'left' | 'center' | 'right'
    formatFieldValue: (fieldKey: string, value: any) => string
    shouldHideField: (fieldKey: string, context: object) => boolean
    getTableColumns: (hideContext?: object) => ColumnConfig[]
    getDetailGroups: () => GroupConfig[]
  }
}
```

### 2. 动态表格组件: DynamicCaseTable

**文件**: `frontend/src/components/DynamicCaseTable.vue`

**特点**:
- 基于 `el-table` 封装
- 根据字段配置动态渲染列
- 支持自定义插槽覆盖默认渲染
- 自动应用格式化规则

**Props**:

```typescript
interface Props {
  data: any[]                    // 表格数据
  columns: ColumnConfig[]        // 列配置
  showSelection?: boolean        // 是否显示选择框
  showActions?: boolean          // 是否显示操作列
  actionsWidth?: number          // 操作列宽度
  loading?: boolean              // 加载状态
  hiddenFields?: string[]        // 隐藏的字段
}
```

**插槽**:
- `cell-{fieldKey}`: 自定义字段渲染
- `actions`: 自定义操作列

### 3. 动态详情组件: DynamicCaseDetail

**文件**: `frontend/src/components/DynamicCaseDetail.vue`

**特点**:
- 基于 `el-descriptions` 和 `el-tabs` 封装
- 支持字段分组显示
- Tab标签页布局
- 自动应用格式化规则

**Props**:

```typescript
interface Props {
  caseData: any                  // 案件数据
  fields: FieldDisplayConfig[]   // 字段配置
  groupConfig?: GroupConfig[]    // 分组配置
}
```

**插槽**:
- `field-{fieldKey}`: 自定义字段渲染

## 📊 字段流转数据结构

### FieldDisplayConfig 数据模型

```typescript
interface FieldDisplayConfig {
  id: number
  tenant_id: string
  scene_type: string              // 场景类型
  scene_name: string              // 场景名称
  field_key: string               // 字段标识
  field_name: string              // 字段名称
  field_data_type?: string        // 字段数据类型
  field_source?: string           // 字段来源
  sort_order: number              // 排序顺序
  display_width: number           // 显示宽度(0=自动)
  color_type: string              // 颜色类型
  color_rule?: ColorRule[]        // 颜色规则
  hide_rule?: HideRule[]          // 隐藏规则
  hide_for_queues?: string[]      // 对队列隐藏
  hide_for_agencies?: string[]    // 对机构隐藏
  hide_for_teams?: string[]       // 对小组隐藏
  format_rule?: FormatRule        // 格式化规则
  is_searchable: boolean          // 是否可搜索
  is_filterable: boolean          // 是否可筛选
  is_range_searchable: boolean    // 是否支持范围检索
}
```

### 三种筛选类型

#### 1. 文本搜索 (is_searchable)

适用于: String类型字段

```vue
<el-input
  v-model="searchValue"
  placeholder="搜索"
  clearable
/>
```

#### 2. 枚举筛选 (is_filterable)

适用于: Enum类型字段

```vue
<el-select
  v-model="filterValue"
  placeholder="全部"
  clearable
>
  <el-option
    v-for="option in enumOptions"
    :label="option.label"
    :value="option.value"
  />
</el-select>
```

#### 3. 范围检索 (is_range_searchable)

适用于: Integer, Decimal, Date类型字段

```vue
<!-- 数字范围 -->
<el-input
  v-model="rangeValue"
  placeholder="范围，如：1000-5000"
/>

<!-- 日期范围 -->
<el-date-picker
  v-model="dateRange"
  type="daterange"
  range-separator="至"
/>
```

## 🚀 使用指南

### 1. 配置字段展示

访问: `字段配置 > 甲方字段展示配置`

1. 选择场景类型
2. 添加字段配置
3. 设置展示属性
4. 配置筛选功能

### 2. 字段自动生效

配置保存后,相应场景会自动应用:
- 控台案件列表
- 催员案件列表
- 催员详情页

### 3. 自定义扩展

使用插槽进行自定义渲染:

```vue
<!-- 表格列自定义 -->
<template #cell-fieldKey="{ row, value }">
  <CustomComponent :data="row" />
</template>

<!-- 详情字段自定义 -->
<template #field-fieldKey="{ value }">
  <CustomDisplay :value="value" />
</template>
```
